# Scrabble Game

Project developed for the Foundations of Programming (FP) course at Instituto Superior Técnico.

## Overview
A fully playable, terminal-based implementation of the Scrabble board game. 

## Key Features
- **Multi-language Support:** Expanded the original project scope to support English, French, and Portuguese dictionaries.
- **Game Logic:** Handles tile drawing, word validation, score calculation, and board rendering.
- **Optimized Loop:** Refactored the vocabulary file parsing and game loop for better performance.

## Technologies
- Python

## How to run
Run the game using: `python3 Main.py`
